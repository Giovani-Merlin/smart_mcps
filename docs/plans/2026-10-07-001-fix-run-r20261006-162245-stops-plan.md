## Decisions

- **`export` refuses rather than warns.** Any `transcript_missing` session
  refuses the export (exit 1, nothing written) unless `--allow-missing`; a
  non-empty `--out` (an `ingest.json` or `events/` already there) refuses
  unless `--clear`, which removes only those two entries. The census runs
  *before* any file is written, so a refusal leaves the target untouched.
  Rationale: the silent bundle cost an hour and a rebuild; the one legitimate
  partial case (r20260902, transcripts gone for good) is a conscious flag.
  Rejected: refuse only when all sessions are missing (partial loss would
  still print "wrote"); warn-only (the driver proved they read "wrote", not
  the count).
- **Result-aware liveness lives in `sign_of_life`, not in a new heartbeat
  fact.** When `child.last_event_type == "result"`, the CPU signal is not
  consulted; a tool child still counts (a queued follow-up turn is announced
  by an `assistant` event before any tool runs, so a post-result tool child
  is itself evidence of a new turn). The existing window then produces the
  `not live` line. Rejected: a streaming-side "result at T, stdin closed at
  T+20 s" fact with its own threshold — richer, but a new field, a new knob
  and two modules for a case the grace close already bounds to 20 s.
- **Phase lines are one `run.log` line per command, plus one per attempt
  start.** `group <gid>: command <n>/<total>: exit <k> (<N.N>s)` after every
  command, and `group <gid>: run recipe attempt <a> starting at command <s>/<total>` before the loop, so a retry carrying forward commands is
  visible. The failure lines stay as they are. Rejected: moving the
  heartbeat label into the log (would spam one line per poll).
- **A surprise whose only targets are its own group is dropped with an
  anchor line, never bucketed.** `mark` logs
  `SURPRISE [kind] group <src> → (own group; already in its report): …` and
  persists nothing. An empty `affected_groups` still goes to `__run__`, and
  the residue reason becomes "no target group named, or an unknown id" so
  `finish` stops claiming an id was unknown when none was given.
- **The live tier runs before every run as a named subset, not the whole
  tier.** Three files guard the worker seam (streaming follow-ups, read roots,
  allowlist patterns); the preflight runs exactly those with `-m llm` under
  `--basetemp=.orchestrator/live-preflight`. The new live test asserts
  termination, never how the CLI folded the follow-ups — folding is
  timing-dependent and a test that pins it would flake.
- **S1 holds at the report gate, not at the merge.** A required
  `Run (driver):` item whose `Run:` is a pytest invocation naming a path
  (`tests/x.py` or `tests/x.py::name`) absent from the worktree becomes a
  gap beside `unmet_required_verification`'s — the same `changes_required`
  round the coder already gets for an unmet item — with a message telling it
  to write the test or report `skipped` with the reason. Rationale: at the
  merge the coder is gone; at the gate it can still write the test.
  Rejected: holding in `merge_ladder` (nobody left to act).
- **S2 scans files, not codegraph, and reads subject-verb only.** The
  Goal-symbol lint finds definitions by a regex over the repo's tracked
  `*.py` files (`git ls-files`, falling back to `rglob` minus `.venv`,
  `.worktrees`, `node_modules`), keeping plan-check's "no codegraph call"
  promise and its sub-second cost. It warns, never fails, and it considers a
  backticked symbol only when a change verb follows it ("`X` gains", "`X`
  becomes"): a Goal names many helpers it merely calls (`log_event`,
  `_split_bullets`), and flagging every mention would make every plan red at
  the preflight that resolves warnings. Rejected: every backticked mention
  (this plan alone would raise nine false warnings); codegraph callers (the
  promise, and a cold index drops symbols).
- **Documentation lands in one trailing unit.** U8 depends on U1–U7 and
  writes every skill, contract and glossary line those units introduce,
  with the exact strings fixed here so the docs coder needs no code reading.
  Rationale: pricing (see resolved context) and one coherent pass over the
  anchor table. Rejected: docs inside each unit (two groups over cap, five
  units paying for the same 39 KB skill file).

No ADR: none of these is hard to reverse or surprising with the notes in hand.
